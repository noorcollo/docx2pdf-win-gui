# Changelog

## 1.0.0 — 2026-09-29

- Added a Windows desktop GUI for queueing `.docx` files and folders.
- Added recursive folder scanning, drag-and-drop, destination-folder selection, progress, and per-file status.
- Added a confirmation before replacing existing PDFs.
- Added startup diagnostics in `%LOCALAPPDATA%\Docx2Pdf\startup.log`.
- Retained the original PowerShell command-line converter and MIT attribution.
